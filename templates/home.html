Fidelity you can inspect

Preserve the page before interpreting the table.

Statements vary by country, language, and layout. Exact_Copy retains all successfully extracted text with approximate page geometry; Table_Data separately attempts to organise detected transactions.

Visual rows first

Headers, summaries, transaction lines, and other extracted text stay in visual reading order instead of being filtered out.

Text before OCR

Native PDF text is used when available. Scanned pages need OCR, which can misread characters or positions and should be checked against the PDF.

Two useful views

Exact_Copy is the layout-preserving extraction. Table_Data is a best-effort convenience sheet for filtering, cleanup, and analysis.

Feedback loop

Flag rows or columns that need attention after a job so the parser can improve against real statement layouts.

Security

Financial files deserve plain rules, not vague promises.

Uploaded PDFs are processed for conversion and expire automatically unless a job is explicitly retained for feedback. Transfers use HTTPS; conversion jobs run independently of one another.
