Workflow

One focused flow, from PDF to spreadsheet.

The product is built around a single job: upload a statement, recreate what's on the page inside Excel, then download and review — nothing extra to configure.

01

Upload the statement

Drop a bank statement PDF in. Text-based and scanned pages route through different extraction paths automatically.

02

Recreate the layout

Text and coordinates — or OCR coordinates for scans — are placed into Excel cells the way they appeared on the page.

03

Download and review

Headers, summaries, transaction lines, and amounts stay as reviewable text so you can clean the sheet for your workflow.

Accuracy direction

Built around table geometry, not one bank's template.

Statements vary by country, language, and layout. The extraction flow prioritizes document structure first, text second, and a reviewable workbook last.

Dynamic headers

Column positions are read from the file and reused when later pages omit the header row.

Text before OCR

Native PDF text is used when available; OCR is reserved for scanned or image-heavy statements.

Review context

Raw extraction context stays in the workbook so unclear rows can be checked, not silently hidden.

Feedback loop

Report a poor conversion after a job so the parser improves against real statement layouts.

Security

Financial files deserve plain rules, not vague promises.

Uploaded PDFs are processed for conversion and expire automatically unless a job is explicitly retained for feedback. Transfers use HTTPS; conversion jobs run independently of one another.
